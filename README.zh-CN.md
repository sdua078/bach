# Bach

[English](README.md) | **简体中文**

> **仅为估算，不构成税务建议。** Bach 与新西兰税务局（IRD）和 ACC 没有任何关联，也未获其认可。结果只是帮你提前存税的估算，以 IRD 的实际计算为准。估算不包括税收抵免、学生贷款、Working for Families 等调整。使用风险自负。

Bach 是一个免费、开源、本地优先的工具，服务对象是在新西兰**有全职 PAYE 工资、同时有自雇（sole trader）副业收入**的人。每笔副业收入到账时，它告诉你该转多少钱到存税账户；到了年底，直接给出 IR3 要填的数字。

*bach（读作 "batch"）是新西兰人周末去的度假小屋。把账理好，安心去 bach。*

## 开始使用

**👉 [sdua078.github.io/bach](https://sdua078.github.io/bach/)**

不用下载，也不用注册账号，在电脑或手机的浏览器里直接打开就能用。

1. **打开网址**，读完说明后填预计年薪。
2. **装成 app**（推荐，数据更安全）：
   - Chrome / Edge：点地址栏右边的安装图标
   - Mac 上的 Safari：文件 → 添加到程序坞
   - iPhone：分享 → 添加到主屏幕
3. **随手记账**
   - *收入*：输入到账的纽币，按回车。Bach 会提示该存多少税，"已存税"填你实际转了多少。
   - *开支*：填项目、类别、金额，以及其中用于副业的比例。
   - *家庭办公*：房租、面积、账单填一次即可。
4. **看汇总页**，了解还要存多少。
5. **定期导出备份**（设置 → 导出备份），大约每月一次，存到 iCloud 或 Google Drive。

## 你的数据

- 只保存在你这台设备的浏览器里。没有服务器，不连银行，不上传任何东西。
- 每台设备、每个浏览器的数据都是独立的。换设备时，先在旧设备导出备份，再在新设备导入（设置 → 导入备份）。导入会替换新设备上的全部数据。
- Safari 可能会清掉一段时间没访问的网站数据，所以请把 Bach 装成 app，并定期备份。

## 目前的功能（v0.1）

- 记录 2026-27 税年的收入和开支，支持设置副业使用比例
- 家庭办公抵扣（房租、电费和燃气、网络）
- 在 PAYE 之外预计还要补多少税、ACC 征费估算、还要存多少
- 剩余应缴税超过门槛时，提示明年可能要交暂缴税
- 中英文界面、浅色和深色模式、电脑和手机布局

## 开发者

只有想修改代码时才需要。需要 Node 22 以上版本和 pnpm。

```sh
pnpm install
pnpm dev        # http://localhost:5173
pnpm test       # 单元测试（计算 + 数据层）
pnpm build
```

| 路径 | 内容 |
|---|---|
| `src/tax-rules/nz-YYYY-YY.json` | 所有税率、门槛和日期，附官方来源链接。税务数字只放在这里。 |
| `src/calc/` | 纯计算函数，以整数"分"计算，全部有单元测试 |
| `src/db/` | Dexie（IndexedDB）数据结构和 `repo.ts`，界面只通过它读写数据 |
| `src/platform/` | 文件、存储、设备等接口的网页版实现（以后可换成原生实现） |
| `src/i18n/` | 带类型的文案字典；`zh.ts` 的 key 必须和 `en.ts` 完全一致 |
| `src/pages/`、`src/components/` | 界面 |

### 新增一个税年

1. 复制最新的 `src/tax-rules/nz-YYYY-YY.json`，按 IRD / ACC 官网逐项更新数字，并更新 `sources`。
2. 在 `src/tax-rules/index.ts` 里注册。
3. 在 `src/calc/incomeTax.test.ts` 里为新税档补充测试。

### 部署

推送到 `main` 后会自动跑测试，用 `BACH_BASE=/<仓库名>/` 打包，并发布到 GitHub Pages（仓库 Settings → Pages → Source 选 GitHub Actions）。
